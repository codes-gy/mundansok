# 04. 유저 스토리

## 페르소나
| | 김개발 (32) | 이운영 (41) |
|---|---|---|
| 상황 | 직원 20명 스타트업의 유일한 백엔드 개발자. 보안 담당은 따로 없음 | 쇼핑몰 운영 팀장. 사이트는 외주 개발사가 만들었음 |
| 고민 | "배포 설정 실수로 뭔가 열려 있진 않을까?" | "보안 점검하라는데 뭘 봐야 하는지 모르겠다" |
| 원하는 것 | 빠르게 돌리고, 고칠 설정을 바로 알고 싶다 | 외주사에 "이걸 고쳐 달라"고 전달할 수 있는 결과 |

## 사용자 여정 (김개발)
1. 도메인 입력 → 2. TXT 레코드 안내를 DNS에 추가 → 3. 인증 → 4. 점검 시작 → 5. 결과에서 "높음"부터 확인 → 6. 설정 수정 후 재점검 → 7. 점수 상승 확인 · 정기 점검 켜기
