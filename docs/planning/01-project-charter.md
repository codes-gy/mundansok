# 01. 프로젝트 헌장

## 한 줄 소개
회사 도메인을 넣으면, 공격자가 밖에서 먼저 보게 될 약점을 찾아 쉬운 말로 알려 주는 외부 노출 점검 서비스.

## 배경
- AI 도구로 공격 준비가 자동화되면서, 노출된 설정 파일 · 만료된 인증서 · 빠진 보안 헤더 · 위조 가능한 메일 도메인을 찾는 **정찰 단계가 대량으로, 빠르게** 이뤄진다.
- 보안 전담 인력이 없는 중소기업은 자기 서비스가 밖에서 어떻게 보이는지 확인할 방법이 없다. 상용 도구는 비싸고 결과가 전문 용어로 가득하다.

## 목표
1. 공격자와 같은 시선으로, **공격 없이** 회사 도메인의 외부 노출을 점검한다.
2. 결과를 **위험도 · 우선순위 · 고치는 방법**으로 정리해 비전문가도 바로 조치할 수 있게 한다.
3. 점검 도구가 **공격 도구로 쓰이지 않도록** 소유 인증 · 요청 제한 · 내부망 차단을 기본으로 둔다.

## 범위
| 포함 (8주) | 제외 |
|---|---|
| 도메인 등록 · DNS TXT 소유 인증 | 포트 스캔 · 취약점 공격 코드 실행 · 로그인 대입 |
| 점검 5종(TLS · HTTPS 전환 · 보안 헤더 · 민감 파일 · SPF/DMARC) | 내부망 · 에이전트 설치형 점검 |
| 점수 · 결과 대시보드 · 조치 가이드 | 서브도메인 전수 탐색(다음 단계) |
| 팀(조직) 단위 도메인 관리 · 정기 점검 · 메일 알림 | 결제 · 요금제 |
| AI 결과 설명(판정은 규칙, 설명만 AI) | |

## 성공 지표
| 지표 | 목표 |
|---|---|
| 점검 1회 소요 시간 | p95 30초 이내 |
| 오탐률 (테스트용 도메인 30개 수동 대조) | 5% 이하 |
| 도메인 등록 → 첫 결과까지 걸린 시간 | 중앙값 5분 이내 (DNS 반영 대기 포함) |
| 결과 화면 이해도 (비개발 직군 5명 사용성 테스트) | "무엇부터 고칠지 알겠다" 4/5 이상 |

- 팀: 5인 (02. 팀 구성 참고)
